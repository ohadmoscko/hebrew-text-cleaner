# מנקה טקסט עברי

ניקוי טקסט עברי שהועתק מ-PDF, מוואטסאפ או ממודל שפה.

**→ [ohadmoscko.github.io/hebrew-text-cleaner](https://ohadmoscko.github.io/hebrew-text-cleaner/)**

הכל רץ בדפדפן. שום טקסט לא נשלח לשרת, אין איסוף מידע, אין הרשמה.
דף אחד, בלי תלויות — אפשר להוריד את `index.html` ולהריץ אותו אופליין.

---

## הבעיה

טקסט שמועתק מ-PDF או מוואטסאפ נראה תקין ומתנהג רע. הוא סוחב איתו תווים
בלתי־נראים שמקפיצים את סדר המילים בטקסט מעורב עברית־אנגלית, ניקוד שנדבק
לכל אות, מקפים ארוכים וגרשיים "חכמים" שנשברים במערכות אחרות.

## מה הכלי עושה

**דלוק כברירת מחדל:**

| פעולה | דוגמה |
|---|---|
| הסרת ניקוד וטעמי מקרא | `שָׁלוֹם` → `שלום` |
| הסרת תווים בלתי־נראים | zero-width, סימני כיווניות, BOM, מקף רך |
| רווח קשיח → רווח רגיל | `U+00A0` → רווח |
| מקף ארוך → מקף רגיל | `—` → `-` |
| גרשיים חכמים → ישרים | `"שלום"` → `"שלום"` |
| שלוש נקודות | `…` → `...` |
| רווחים כפולים ורווחי סוף שורה | |
| יותר משתי שורות ריקות ברצף | |

**כבוי כברירת מחדל — פעולות שמשנות משמעות:**

- איחוי שורות שנקטעו באמצע משפט (טיפוסי ב-PDF)
- גרשיים ישרים → עבריים: `צהל` → `צה״ל`, `גינס` → `ג׳ינס`
- הסרת סימוני Markdown
- תבליטים → מקף
- מחיקת שורות ריקות

## מה הכלי לא נוגע בו

- **מקף עברי** (`U+05BE`), **גרש** `׳` ו**גרשיים** `״` עבריים נשארים כמו שהם.
- **רווח קשיח מומר ולא נמחק** — מחיקה הייתה מדביקה מילים.
- **המרת גרשיים לעבריים תופסת רק ראשי תיבות** בתבנית אות־גרשיים־אות אחרונה.
  `ו"ציטוט"` לא נתפס. המחיר: גם `ביהמ"ש` לא נתפס. החמצה עדיפה על הרס טקסט.
- **איחוי שורות לא מאחה תבליטים ורשימות ממוספרות.**

## שימוש

פתח את [הדף](https://ohadmoscko.github.io/hebrew-text-cleaner/), הדבק, העתק את התוצאה.
המונה ליד כל פעולה מראה כמה שינויים היא ביצעה בפועל — שימושי כדי לראות
מה דווקא היה מלוכלך בטקסט.
